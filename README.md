VELMARIS — a travel poster for a place that does not exist: a cliff town
where waterfalls pour from islands floating in a violet dusk sky into a
turquoise sea, watched over by a lighthouse on a needle rock. Drawn
procedurally in pure Python (standard library only, deterministic, no
network at runtime); the place name is set in large hand-built vector
capitals and no other copy appears on the poster.

## Run it

```sh
python3 main.py /output/entry.png
```
